# Progress Block

Интерактивный компонент кругового прогресса для мобильных веб-приложений

## Описание

Progress Block - это переиспользуемый UI-компонент для отображения прогресса выполнения процессов. Компонент реализован на чистом JavaScript без использования сторонних библиотек и адаптирован для мобильных устройств.

### Основные возможности

- **Отображение прогресса** - круговая диаграмма с дугой от 0 до 100%
- **Три состояния**:
  - `Normal` - базовое отображение с управлением через Value
  - `Animated` - вращение блока по часовой стрелке
  - `Hidden` - скрытие блока с сохранением места в вёрстке
- **Адаптивность** - поддержка портретной и ландшафтной ориентации
- **Управление** - интуитивные контролы: числовое поле и переключатели

## Макет

Начало дуги соответствует **12 часам**, конец дуги движется **по часовой стрелке** при увеличении значения.
